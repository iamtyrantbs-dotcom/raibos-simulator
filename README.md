# Raibos Simulator Online

A powerful incremental clicker game with a global leaderboard system.

## Features
- **Endless Progression**: Numbers scale beyond Decillion into alphabetical notation (aa, ab, ac...).
- **Global Leaderboard**: Compete with players worldwide for the top spot in Raibos, RP, Clicks, and more.
- **Deep Rebirth System**: Rebirth to gain RP and multiply your production.
- **Earth Invasion**: High-stakes RNG system to obtain powerful relics and gamepasses.
- **Rich Aesthetics**: Modern UI with smooth animations and dynamic effects.

## How to Run Locally
1. Install [Node.js](https://nodejs.org/).
2. Run `npm install` to install dependencies.
3. Start the server with `node server.js`.
4. Open `http://localhost:3000` in your browser.

## Deployment
This project is ready to be deployed to [Render.com](https://render.com/) or similar Node.js hosting services.
